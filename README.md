# MorphIcon 🔄

Una librería ligera para **Android** que permite crear **íconos morfables** con animaciones fluidas.  
Ideal para transiciones de menú, botones de acción o cualquier caso donde quieras que un ícono cambie dinámicamente a otro.

---

## 🚀 Características
- Animaciones suaves entre diferentes formas de íconos.  
- Fácil integración en cualquier proyecto Android.  
- Basado en **Kotlin** y **AndroidX**.  
- Incluye un **sample app (`app/`)** para ver ejemplos en acción.
